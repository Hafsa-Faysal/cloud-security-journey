# cloud-security-journey
## The 5 Phases
### Phase 1: Foundations (Nov 9 - Jan 3)

Bigger areas: Linux, networking, Python, Git, daily puzzles

- Linux basics and everyday use (Linux Journey, terminal commands, a backup script)
- Networking concepts and Wireshark (plus the “What happens when I open a website?” write-up)
- Python basics (CS50P) and three scripts: file organizer, port checker, log parser
- Git and GitHub, with notes in Notion
- Daily puzzles: Bandit 0-20, then picoCTF
- Finish line: Bandit 0-20, three Python scripts, the website write-up, a tidy GitHub repo

### Phase 2: AWS fundamentals (Jan-Mar 2027)

Bigger areas: cloud concepts, core AWS services, first big project, first cert

- Cloud concepts and the AWS Cloud Practitioner Essentials course
- Core services: IAM, S3, EC2, VPC basics, billing alerts
- HTML/CSS refresher (for your resume page)
- Cloud Resume Challenge: static site on S3, HTTPS with CloudFront, a Python Lambda visitor counter with DynamoDB, all defined in Terraform and deployed with GitHub Actions
- Practice questions, then the AWS Cloud Practitioner exam (about $100, your one planned cost)
- Finish line: live Cloud Resume site, public code, cert passed

### Phase 3: Security layer (Apr-Jun 2027)

Bigger areas: fundamentals, offense, defense, cloud security

- Security fundamentals: CIA triad, common attacks, cryptography basics, authentication vs. authorization
- Offense basics: Nmap, Burp Suite, TryHackMe beginner paths, PortSwigger labs
- Defense: a Wazuh home lab, log analysis, a few detection rules
- Cloud security: least-privilege IAM, S3 misconfigurations, CloudTrail, GuardDuty, CloudGoat labs
- Finish line: home lab running and 3 public write-ups

### Phase 4: Capstone (Jul-Aug 2027)

Bigger areas: design, build, attack, document

- Design a small secure AWS environment on paper first
- Build it with Terraform (network, IAM, logging, monitoring)
- Attack it yourself, find weaknesses, and fix them
- Write a README that tells the story: problem, build, attack, fix, lessons
- Finish line: one polished capstone project on GitHub

### Phase 5: University and job hunt (Sep-Dec 2027)

Bigger areas: students perks, community, applications

- Claim student benefits (GitHub Student Developer Pack, Azure for Students if available to you)
- Join a campus cyber or cloud club and play CTFs
- Polish your CV and LinkedIn, then apply for internships and junior cloud or SOC trainee roles
- Finish line: applications sent and real conversations started
